LIMIKO STUDIO · REFERENCES NOTEPAD
==================================
Every outside project this studio learned from or can load, in one place.
The skill's own text, styles and playbooks are written fresh; nothing below is
copied into them. Links were checked on 2026-11-02. Star counts are as GitHub
showed them that day and are not a quality guarantee.

Commercial column:  yes   = permissive (MIT / Apache-2.0 / CC0), fine for paid channels
                    check = read the licence first (custom, AGPL, GPL, unclear, or model weights differ)
                    no    = non-commercial; tests only

Line format (the loader script reads these lines; keep the shape):
[id] owner/repo | category | licence | commercial | kind | one-line use
     kind: skill (agent skill or plugin), tool, model, assets, list
