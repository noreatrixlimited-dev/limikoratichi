# 1 · Kids videos

**Promise:** warm, safe, colourful stories, songs and learning for ages 2–8.
**Files here:** `styles.md` (looks) · `packaging.md` (hooks, titles, tags) · this playbook.

## Settings
| | Default |
|---|---|
| Formats | story episode 3–8 min · song 1.5–3 min · Short 30–60 s · learning clip 1–2 min |
| Size | 1920×1080 first (TV and tablets), then a 1080×1920 cut for Shorts |
| Route | A · code-drawn (`../../shared/building.md`) |
| Voice | warm, smiling, slow (120–140 wpm), clear consonants; `A-kokoro` |
| Music | major key, glockenspiel / ukulele / marimba / music box, 90–120 bpm |
| Loudness | −16 LUFS, no peak jumps over 6 dB |
| Engines | `E-book` (story pages), `E-html`, `A-rhubarb` (2D lip sync), `G-kenney`, Quaternius |

## Video types and their structure
| Type | Structure |
|---|---|
| **Bedtime / moral story** | greeting → hero wants something → small problem → three tries (rule of three) → kind solution → one-line lesson → sleepy goodbye |
| **Learning clip** (colours, numbers, shapes, letters, animals) | hook question → show item → say it twice → item in a scene → quick quiz pause (3 s) → recap all items |
| **Song / rhyme** | 8-bar intro with the hero → verse → chorus (same picture every time) → verse → chorus ×2 → wave goodbye. Public-domain rhymes are free to use; write new verses for originality |
| **How things work** | "What happens when…?" → follow one thing step by step → big reveal → "now you know!" |
| **Short** | the funniest or cutest 20 s of an episode + a question on screen |

## Procedure
1. **Pick one goal** (a word, a number, a feeling, a habit) or one gentle story arc.
2. **Hero:** reuse the channel's recurring character (simple silhouette, 3 colours, a catchphrase).
   Keep a character sheet in `films/_characters/<name>.md` (colours, shape, voice, catchphrase).
3. **Script** with the structure above. New words appear on screen and are said twice.
4. **Shot list:** shots 3–5 s, slow camera, one action per shot, characters face the camera when they talk.
5. **Voice first**, then lip sync (2D mouth shapes) and animation timed to it.
6. **Build** in a style from `styles.md`, render, mix.
7. **Safety check** (all must pass):
   - [ ] no flashing more than 3 times per second, no strobe, no shaking screen
   - [ ] no sudden loud sounds, no scary faces, no danger shown as fun (fire, roads, water, medicine)
   - [ ] no brands, no toys or mascots that look like existing franchise characters
   - [ ] kind language only; nobody is laughed at
   - [ ] captions large (≥ 6% of height), high contrast
8. **Package** with `packaging.md`. Upload with **Made for kids** set in YouTube Studio.
9. Make the vertical Short from the best 30 s.

## Series ideas
Bedtime stories with one hero · colours / shapes / numbers songs · "animal sounds" · "how does a … work?" ·
manners and feelings · seasons and weather · counting adventures · alphabet animals.
