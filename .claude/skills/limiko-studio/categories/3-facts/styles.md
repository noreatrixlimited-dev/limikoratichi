# Facts styles

Drawn in code with `../../shared/building.md`. 🟢 easy · 🟡 medium · 🔴 heavy.

|---|---|---|---|---|

## Facts look rules
- One accent colour for "the important thing"; everything else neutral.
- Numbers are the biggest thing on screen when spoken.
- Source line (small, bottom corner) on any shot with a statistic.
