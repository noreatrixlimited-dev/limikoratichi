# 3D characters, objects and worlds (Route E)

## Choose the path
| Situation | Path | Engines |
|---|---|---|
| Stylised scene, no Blender installed | Three.js in the code-drawn pipeline (`styles/building.md`) | `D-3dviz` |
| Need a mesh from a picture or text | Image/text-to-3D | `D-trellis` (MIT), `D-dreamg` (MIT), `D-hy3d` (check licence) |
| Free ready-made characters and props | CC0 assets | `guides/assets.md` (Quaternius, Kenney, Poly Haven, `G-glb`) |
| Character must move | Mixamo-style rig + motion | `D-mocap`, `D-mocap2`, `D-prompt2rig`, `D-motion` |
| Full Blender scene by voice | Blender + agent control | `D-blender-mcp`, `D-blender94`, `D-blender52`, `D-blender-game` |
| Talking 3D avatar | Browser avatar with lip sync | `D-talkinghead` |

## Three.js recipe for a code-drawn 3D film
1. Load GLB assets with `GLTFLoader`; play their animation clips with `AnimationMixer`.
2. Drive everything from `renderFrame(t)`: call `mixer.setTime(t)` and set the camera from a
   keyframe list. Never use the clock.
3. Look presets: flat-shaded low-poly (`MeshLambertMaterial`, `flatShading: true`), toy plastic
   (`MeshPhysicalMaterial` clearcoat 1), clay (roughness 0.9, warm light), glass (transmission 1).
4. Light: one key directional with soft shadows, hemisphere fill, rim light for silhouettes.
5. Render at the target size with `preserveDrawingBuffer: true` so screenshots capture the frame.

## Blender recipe
1. Assemble in Blender (CC0 assets plus generated meshes), rig with Mixamo-compatible bones.
2. Retarget motion (video mocap or text-to-motion engine).
3. Render EEVEE for speed or Cycles for hero shots; PNG sequence; then encode and mix with ffmpeg.
