# Facts packaging

General rules: `../../shared/packaging.md`.

## Hooks (first 2 s)
| Pattern | Example shape |
|---|---|
| Wrong belief | "Everything you know about <X> is wrong" (only if it really is) |
| Impossible claim | "This <thing> shouldn't exist, but it does" |
| Direct question | "Why does <everyday thing> <surprising behaviour>?" |
| Scale shock | "<small thing> next to <huge thing>" shown at once |
| Number promise | "<N> facts about <X> that sound fake" |
| Hidden in plain sight | "You've seen this <N> times today and never noticed" |
| What if | "What if <scenario> for just one day?" |

## Titles
- `Why Does <X> <Y>?` · `<N> <Topic> Facts That Sound Fake` · `What If <Scenario>?`
- `The Real Size of <X>` · `<X> vs <Y>: <Question>` · `How <Everyday Thing> Actually Works`
- Searchable noun first, 40–60 characters, no false claims in the title.

## Thumbnail
One striking object or comparison, huge and clear; 1–3 words of tension ("THIS IS REAL?"); one arrow.

## Description template
```
<The surprising fact in one line, with the main search phrase.>
<What the video explains, second search phrase.>

⏱ 00:00 <hook> · 00:20 <beat> …

Sources:
1. <title>, <publisher>, <year>: <link>
2. …

#facts #<topic> #didyouknow
```

## Tag set (8–12)
`<topic> facts, facts about <topic>, did you know, interesting facts, fun facts, <topic> explained,
science facts, amazing facts, <specific noun>, <series name>, educational`
