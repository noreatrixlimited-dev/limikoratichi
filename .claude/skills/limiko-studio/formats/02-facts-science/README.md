# 3 · Facts and interesting things

**Promise:** one surprising, true idea per video, understood fast and remembered.
**Files here:** `styles.md` · `packaging.md` · this playbook.

## Settings
| | Default |
|---|---|
| Formats | Short 35–55 s · list video ("10 facts") 6–10 min · deep-dive 8–15 min |
| Size | 1080×1920 Shorts · 1920×1080 long |
| Route | A · code-drawn; B for photoreal moments; real public-domain images where useful |
| Voice | confident, curious, 160–175 wpm; `A-kokoro` |
| Music | low pulse 90–110 bpm under voice; a sound effect on every reveal |
| Pace | Shorts median shot 1.5–2.5 s; a new visual every sentence |
| Engines | `E-explain`, `E-talk`, `E-manim` (maths and science), `E-html`, `E-collage` |

## Video types
| Type | Structure |
|---|---|
| **Single fact Short** | claim (hook) → "here's why" → 2–3 proof beats → bigger implication → loop line back to the claim |
| **"N facts" list** | strongest fact first as a teaser → count up (or down) → best one held for last → recap |
| **"What if…"** | the scenario → first effect → chain reaction → the surprising end state |
| **Comparison / scale** | small thing → zoom out step by step → huge thing, with numbers on screen |
| **Myth vs fact** | the myth stated as people believe it → "actually…" → proof → what's really true |
| **How it works** | the everyday object → open it up → each part in order → "so next time you…" |

## Procedure
1. **Verify first.** Every fact needs two independent reliable sources (encyclopaedia, university,
   government, major science publisher). Write them in `films/<slug>/sources.md` with links.
   If it can't be verified, drop it. Mark estimates as estimates. Put the year next to numbers.
2. **Script**: about 2.5 words per second; one idea per sentence; no filler intros.
3. **Visual plan**: every number becomes a graphic, every comparison is shown side by side.
4. **Build** in a style from `styles.md`; captions on; punch-in on each key number.
5. **Sound**: "ding" or whoosh on reveals, riser before the twist, silence for 0.3 s before the payoff.
6. **Check**:
   - [ ] each claim traced to `sources.md`
   - [ ] nothing presented as fact that's a theory or a rumour
   - [ ] hook readable with sound off
   - [ ] last line loops back to the first frame (Shorts rewatch)
7. **Package** with `packaging.md`; list sources in the description.
