# 07 · Anime and cartoon: direction profile

**Identity:** expressive character animation, consistent designs, dynamic poses, cinematic framing,
emotional close-ups and real action sequences. Intensity matches the story; effects are timed, not random.

> **Moving-camera rule:** the camera moves in every shot (see `../../shared/directing.md` §0).

## Numbers
| | |
|---|---|
| Median shot | 2 s (0.5–5 s); emotional close-ups 3–5 s; action 0.5–1.2 s |
| Camera | dramatic angles (low for power, high for weakness), slow push on close-ups, pans across painted backgrounds, smash zoom in action, shake on impact |
| Animation | anime: limited animation on twos/threes with strong key poses and smears; cartoon: full squash and stretch 20–40% |
| Effects max | level 3 in drama, level 4–5 in action peaks (speed lines, impact frames, aura glows, sparkles) |
| Transitions | cut, match cut, whip, flash on impact, wipe for comedy; eyecatch card between acts |
| Sound | character voices, foley, stingers; score with leitmotifs per character |

## Character rules
G3 reference sheets mandatory: turnaround, 5+ expressions, hand poses, colour model (hex), outfit
variants. Eyes, hair silhouette and colour blocks are the identity: never change them between shots.
Keep an **expression sheet** for every main character and pick expressions from it.

## Shot grammar
Establishing (painted background) → character intro (low angle, hold) → dialogue (shot / reverse shot,
180° rule) → emotional close-up (eyes, slow push, background simplified to colour or bokeh) →
action (wide for geography, then tight cuts, then a held impact frame) → aftermath (wide, quiet).

## Styles
| id | Look | For |
|---|---|---|
| `anime-cel` | clean line art, two-tone cel shading, painted skies | drama, adventure |
| `anime-impact` | speed lines, impact frames, black-and-white flashes | fights, hype moments |
| `chibi-comedy` | big heads, tiny bodies, sweat drops, sparkle eyes | comedy shorts |
| `bendy-cartoon` | 1930s rubber limbs, pie-cut eyes | slapstick |
| `space-sitcom` | rounded flat sci-fi cartoon | comedy series |
| `fifties-flat` | mid-century flat shapes | stylish cartoon stories |

## Special planning (G4)
Beat sheet with emotion per beat; for action scenes a **fight map** (positions, who has the advantage,
the turn, the finishing move) so the geography stays clear.

## Packaging
Hooks: the emotional peak frame, the impossible moment, the character's catchphrase. Thumbnail: the
character's strongest expression, large, with a colour-contrast background.

## Checklist
- [ ] Character designs match the sheets in every shot (eyes, hair, colours)
- [ ] Action geography readable (wide before tight)
- [ ] Effects timed to impacts and beats, not continuous
- [ ] Original characters only; nothing resembling existing franchises
