# Kids packaging

General rules: `../../shared/packaging.md`. This page has the kids-specific patterns.
Parents search, children click, so the title is for the parent and the thumbnail is for the child.

## Hooks (first 2 s, on screen + voice)
| Pattern | Example shape |
|---|---|
| Wonder question | "What if a <animal> could <magic action>?" |
| Hero greeting + promise | "Hi friends! Today <hero> learns to <skill>!" |
| Surprise reveal | box/egg/door opens on the first beat |
| Sing-along start | chorus line first, then the song from the top |
| Mini quiz | "Can you find the <colour> <thing>?" |
| Problem in one line | "Oh no, <hero> lost <thing>!" |

## Titles (parent search words first)
- `<Topic> for Kids | <Hero> <Story/Song>`: e.g. shapes, colours, numbers, ABC, animals
- `<Hero> and the <Thing> | Bedtime Story for Kids`
- `Learn <Topic> with <Hero> | Toddler Learning Video`
- `<Topic> Song | Nursery Rhymes & Kids Songs`
- 40–60 characters; no ALL CAPS, no clickbait, no "shocking".

## Thumbnail
The hero's happy face large, one bright object, 0–2 words (e.g. "COLOURS!"), clean background.

## Description template
```
<Hero> <does what> in this <story/song> for kids! Learn <topic> with fun <style> animation.
Perfect for toddlers and preschool (ages 2–6).

In this video:
00:00 Hello!
00:20 <part>
…

#kidsvideos #<topic>forkids #<hero>
```

## Tag set (pick 8–12)
`kids videos, <topic> for kids, learn <topic>, toddler learning, preschool learning, nursery rhymes,
kids songs, bedtime stories for kids, cartoon for kids, <hero name>, <series name>, educational videos for kids`

## Kids channel rules
- Set **Made for kids** (YouTube requirement); comments and personalised ads are off.
- No links out, no calls to buy, no "comment below".
- End screen: next episode of the same series.
