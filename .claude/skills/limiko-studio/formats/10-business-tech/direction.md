# 10 · Business, technology and product: direction profile

**Identity:** clean modern motion graphics, precise typography, 3D product demonstrations, interface
animations, cinematic product light, structured storytelling. The product or main subject is always the focus.

## Numbers
| | |
|---|---|
| Median shot | 2.5 s (1.5–4 s) |
| Camera | smooth orbits around the product (10–30°), slow push-ins on features, precise tracking along UI flows |
| Animation | on ones, crisp easing (cubic-out), UI elements slide 20–40 px and fade, nothing wobbles |
| Effects max | level 2 (soft shadows, reflections, light sweeps, depth blur) |
| Transitions | cut, match cut on shapes, zoom-through into the screen or product, clean wipe on a grid |
| Type | one sans family, 2 weights, generous spacing, left-aligned grid |
| Sound | clean UI clicks and swooshes, modern score 100–120 bpm, confident narration |

## Story structure
Problem (5–10 s) → product reveal (hero shot) → 3 key features (each: what → how it looks in use → benefit,
with one number) → proof (testimonial, metric, comparison) → call to action.

## Building blocks
- **Hero product shot**: 3D model on a seamless background, rim light + key light, slow orbit, glass/metal materials (`glass-tech`).
- **Feature call-outs**: thin leader lines, labels draw on, the feature highlighted, the rest dimmed.
- **UI animation**: recreate the interface as HTML at real size, animate the cursor and taps, zoom into the detail.
- **Exploded view**: parts separate on axes to show what's inside.
- **Data**: one number per screen, large, counting up.

## Styles
`glass-tech` · `exploded-view` · `iso-diagram` · `data-story` · `kinetic-type` · `holo-hud` (futuristic tech) ·
`clean-ui` (flat interface on soft gradient) · `swiss-grid` (bold typographic layouts).

## Special planning (G4)
Concept plan per feature: the feature, the visual mechanism (UI flow, exploded view, demo), the number,
and the benefit line.

## Packaging
Hooks: the problem in one line, the product doing the impossible, the key number. Titles:
`<Product>: <Benefit> in <Time>`, `How <Product> <Solves Problem>`.

## Checklist
- [ ] Product or subject is the focus in every shot
- [ ] Brand colours, logo and fonts exact (from the brief)
- [ ] Numbers and claims verified
- [ ] Clean motion: no wobble, no random effects
