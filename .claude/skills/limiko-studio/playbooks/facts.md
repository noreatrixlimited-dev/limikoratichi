# Facts channel playbook

**Promise:** one surprising, true idea per video, understood in under a minute.

| Setting | Default |
|---|---|
| Length | Short 35–55 s · long-form 6–10 min |
| Size | 1080×1920 Short · 1920×1080 long |
| Styles | `whiteboard-hand`, `iso-diagram`, `data-story`, `evidence-board`, `satellite-pass`, `newsreel-1920`, `blueprint-sheet`, `microscope-lens` |
| Voice | confident, curious, 160–175 wpm, `A-kokoro` |
| Music | low pulse 90–110 bpm, ducked; a sound effect on every reveal |
| Hook patterns | wrong belief, impossible claim, direct question, comparison (packaging.md #2, #3, #5, #11) |

## Procedure
1. **Verify the fact.** Two independent reliable sources; write them in `films/<slug>/sources.md`.
   If it can't be verified, don't make it. Put numbers on screen with their year.
2. Script: hook (claim) → "here's why" → 3 beats each with one visual → twist or bigger implication → loop line.
3. One visual idea per beat; every number appears as a graphic.
4. Build (Route A), captions on, punch-in on each key number.
5. Package: title asks the question; thumbnail shows the two things being compared.
6. Description: line 1 promise, then sources list.

## Series ideas
"Why does…", "What if…", "The real size of…", "History in 60 seconds", "Myth vs fact".
