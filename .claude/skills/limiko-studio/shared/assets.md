# Free assets for commercial channels (Route G)

Default to **CC0** (no credit, no limits). Anything else: record the licence in `films/<slug>/credits.txt`.

| Need | Where (ids from REFERENCES.txt or the websites listed there) |
|---|---|
| Cute 3D characters, animals, nature | Quaternius, Kenney 3D, `G-glb`, `G-3d` |
| 2D characters, tiles, UI, icons | Kenney 2D (`G-kenney` downloader), `G-2d`, OpenGameArt (filter CC0) |
| Nature textures, HDRI skies, PBR | Poly Haven, ambientCG |
| Pixel art and effects | `G-pixelfx`, `G-sprites` (generate our own sprites) |
| Public-domain images, film, music | `G-uncopyright`, `G-cc0list` |
| Sound effects | Kenney audio packs, Freesound (CC0 filter) |
| Music | our own (`A-acestep`, `A-yue`), or the user's Suno tracks under their plan's terms |
| Voice | `A-kokoro` default; our own cloned voice only with consent |
| Fonts | Google Fonts (OFL), safe to burn into video |

## Kids-channel asset rules
- Rounded shapes, high-contrast primary colours, no scary faces, no realistic weapons.
- No brand characters, toys or mascots that look like existing franchises.

## Procedure
1. Search the sources above for the brief's nouns (e.g. "fox", "forest", "rain").
2. Download into `films/<slug>/assets/`, one folder per source.
3. Write `credits.txt`: asset, source URL, licence, author.
4. Prefer one source's style per film so the assets match.
