# Style library

Every style here is drawn in code (canvas 2D, SVG or WebGL) and rendered frame by frame.
Pick one by id. Each card says how it **looks**, how it **moves**, how it **sounds**, and what it's **for**.
To build one, read the card, then `building.md` in this folder for the shared technique.

Ratings: 🟢 easy (an afternoon) · 🟡 medium · 🔴 heavy (WebGL / many layers)

### Matching a style to a request
1. Channel first (section above).
2. Mood: calm → watercolor / ink / one-stroke; energetic → kinetic-swiss / micro-games / bendy-cartoon; mysterious → evidence-board / liminal-tape / halftone-file.
3. Budget: under 30 min of build → 🟢; a hero video → 🟡/🔴.
4. Say why in one line when you propose it, and offer one alternative.
